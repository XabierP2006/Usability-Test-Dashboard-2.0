# UX Improvement Project — Xabier Perez

## Introducción
Este proyecto corresponde al análisis y rediseño del sistema institucional “Usability Test Dashboard 2.0”, aplicando metodologías de Interacción Humano Computador (HCI) y experiencia de usuario (UX).

El objetivo principal es detectar problemas de usabilidad presentes en el aplicativo actual y desarrollar propuestas de mejora visual y funcional enfocadas en optimizar la interacción del usuario dentro del sistema. :contentReference[oaicite:0]{index=0}

# Propósito del Proyecto

## Objetivo Principal
Mejorar la experiencia de usuario del aplicativo institucional mediante técnicas de evaluación heurística, arquitectura visual y diseño UX centrado en el usuario.

## Metas Específicas

- Analizar problemas de interacción en el sistema.
- Aplicar principios heurísticos de usabilidad.
- Rediseñar componentes críticos del dashboard.
- Mejorar la navegación y organización visual.
- Implementar funcionalidades UX modernas.
- Mantener evidencia técnica organizada mediante GitHub.
